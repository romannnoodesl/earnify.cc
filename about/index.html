About Earnify

Earnify is an open-source browser mining platform that lets website publishers convert idle visitor CPU cycles into revenue like a browser-based crypto mining service. No ads. No tracking. No consent middlemen. One script tag, a wallet address, and the mining starts.

Browser mining is cryptocurrency mining that runs inside a visitor's browser using Web Workers and WebAssembly. Earnify was built to make this model viable again after the Coinhive era — modern, ASIC-resistant algorithms, a client-side-only architecture, and economics that actually favor the publisher: a flat 10% fee with 90% of yield paid directly to your wallet.

What is Earnify?
Earnify is a free, open-source (MIT) JavaScript miner that connects a website visitor's browser directly to a mining pool over the WebSocket Stratum protocol. It processes zero personal data, uses no cookies, and has no backend — publishers self-host the script or load it from earnify.cc and configure their own Dogecoin wallet for payouts.

Our Position

We believe the ad-supported web is structurally broken: 42.7% of users run ad blockers (Statista 2024), CPMs decline year over year, and ad-tech intermediaries extract 50–70% of inventory value. Earnify's compute model replaces that with one as straightforward as math, public and deterministic.

Principles

  • Zero data by design. No cookies, no localStorage, no fingerprinting — balance hashes and nothing else.
  • Open source forever. Every line under MIT. Audit it, fork it, self-host it.
  • Direct connection. Browsers talk to your pool. Earnify sits nowhere in the money flow.
  • Consent-aware. Opt-in by architecture, with a always-available stop() API.
