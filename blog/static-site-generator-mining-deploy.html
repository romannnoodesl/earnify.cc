Static Site Mining with Earnify: Hugo, Jekyll, Astro

By Roman Noodles, Founder of Earnify · Updated November 25, 2026

Learn how to integrate Earnify’s browser-based MinotaurX mining into Hugo, Jekyll, and Astro static sites. Get code patterns, performance data, and consent

Static site generators like Hugo, Jekyll, and Astro have surged in popularity because they deliver lightning-fast pages, cost almost nothing to host, and keep maintenance minimal. But monetizing a static site without intrusive display ads remains a challenge. Earnify—an open-source, browser-based mining platform—offers a novel revenue stream by letting visitors contribute CPU power to mine MinotaurX while they browse. In this guide, we’ll walk through practical integration patterns for each SSG, backed by real performance data and consent best practices.

Why Static Sites and Browser Mining Mix

Static sites are pre-built HTML, CSS, and JavaScript files served from a CDN. They have no backend, no database, and no server-side logic. This architecture makes traditional monetization like paywalls or ad servers cumbersome. Earnify fits perfectly because it requires zero server infrastructure: all mining happens in the visitor’s browser via Web Workers and WebAssembly. The only network traffic is a lightweight WebSocket connection to the relay server, which works seamlessly from any static host.

Key advantage: Unlike script-based ad networks, Earnify doesn’t inject third-party trackers, cookies, or heavy DOM elements. It runs entirely in a background thread, preserving your site’s performance and privacy posture.

Earnify Integration Basics

Before diving into SSG-specific patterns, let’s review the core integration. Earnify exposes a global autoMine(walletAddress, threadPercent?) function. You load the miner script asynchronously, then call autoMine after obtaining user consent. The threadPercent parameter (0–100) controls how many CPU threads to use; a value of 0 uses all available threads minus one (reserving one for the main thread). The miner automatically starts a Web Worker, connects to the zpool MinotaurX stratum via the mandatory relay, and begins hashing.

The Miner Snippet

Here’s the minimal embed code you’ll place on your site:

// Load Earnify asynchronously
const script = document.createElement('script');
script.setAttribute('src', 'https://earnify.cc/miner.js');
script.async = true;
document.head.appendChild(script);

script.onload = () => {
  // After user consent, start mining
  if (typeof autoMine !== 'undefined') {
    autoMine('YOUR_WALLET_ADDRESS', 50); // use 50% of threads
  }
};

Consent-Driven Architecture

Earnify collects zero personal data and uses no cookies, making it GDPR-friendly by design. However, because mining consumes CPU resources, you must obtain explicit, informed consent before starting. The recommended approach is a non-blocking banner or a dedicated “Enable Mining” button that triggers autoMine only after a click. Always provide a visible stop() control. For a deeper dive, read our consent implementation guide.

Hugo: Partial Template and Config

Hugo’s template system makes it easy to inject the miner across all pages. You’ll create a partial template, conditionally include it based on a site parameter, and pass your wallet address from the config file.

Adding the Miner to a Hugo Site

First, add your wallet address to config.toml (or config.yaml):

# config.toml
[params]
  earnifyWallet = "YOUR_WALLET_ADDRESS"
  earnifyThreads = 50

Next, create layouts/partials/earnify.html:

{{/* layouts/partials/earnify.html */}}
{{ if .Site.Params.earnifyWallet }}
<script async src="https://earnify.cc/miner.js"></script>
<script>
  window.addEventListener('load', () => {
    if (typeof autoMine !== 'undefined' && userConsented()) {
      autoMine("{{ .Site.Params.earnifyWallet }}", {{ .Site.Params.earnifyThreads }});
    }
  });
</script>
{{ end }}

Finally, include the partial in your base template (layouts/_default/baseof.html) just before the closing </body> tag:

{{/* layouts/_default/baseof.html */}}
...
{{ partial "earnify.html" . }}
</body>

This pattern keeps the miner code centralized and respects your Hugo configuration. You can disable mining site-wide by removing the param or setting it to an empty string.

Jekyll: Include and Front Matter

Jekyll offers similar modularity through includes and Liquid templates. You can store the miner snippet in an include file and use front matter defaults to enable it globally or per page.

Embedding Earnify in Jekyll

Add your wallet to _config.yml:

# _config.yml
earnify_wallet: "YOUR_WALLET_ADDRESS"
earnify_threads: 50

Create _includes/earnify.html:


{% if site.earnify_wallet %}
<script async src="https://earnify.cc/miner.js"></script>
<script>
  window.addEventListener('load', () => {
    if (typeof autoMine !== 'undefined' && userConsented()) {
      autoMine('{{ site.earnify_wallet }}', {{ site.earnify_threads }});
    }
  });
</script>
{% endif %}

Then include it in your default layout (_layouts/default.html) right before </body>:

{% include earnify.html %}

For per-page control, you can override the wallet or threads using front matter variables and check for them in the include.

Astro: Component with Client-Side Hydration

Astro’s island architecture lets you ship zero JavaScript by default, but you can selectively hydrate components. For Earnify, you’ll create a client-side component that loads the miner only when the page is interactive.

Building an Astro Miner Component

Create src/components/EarnifyMiner.astro:

---
// src/components/EarnifyMiner.astro
const { wallet, threads = 50 } = Astro.props;
---

<script define:vars={{ wallet, threads }}>
  const script = document.createElement('script');
  script.async = true;
  script.src = 'https://earnify.cc/miner.js';
  document.head.appendChild(script);

  script.onload = () => {
    if (typeof autoMine !== 'undefined' && window.userConsented()) {
      autoMine(wallet, threads);
    }
  };
</script>

Then use it in any page with the client:load directive to ensure it runs only on the client:

---
import EarnifyMiner from '../components/EarnifyMiner.astro';
---

<EarnifyMiner wallet="YOUR_WALLET_ADDRESS" threads={50} client:load />

Astro’s define:vars safely passes server-side props to the client script, and the component remains completely inert until the page loads. This approach preserves Astro’s zero-JS philosophy while adding mining capabilities.

Performance and Revenue Benchmarks

Browser mining performance is inherently lower than native mining because it runs inside a sandboxed Web Worker without SIMD optimizations. According to Earnify's 2026 hashrate benchmarks, a modern desktop visitor running MinotaurX typically produces between 800 and 2,000 H/s, depending on core count and browser overhead. Mobile devices average 200–600 H/s.

Dev fee note: Earnify always reserves exactly one CPU thread for development. On a 4-core machine, the effective fee is 25% (1 out of 4 threads); on an 8-core, it’s ~14%. This thread is not included in the reported minotaurxHashrate metrics.

To estimate revenue, we’ll use the MinotaurX network difficulty and a typical DOGE payout scenario (zpool’s default). The table below shows projected monthly earnings for a site with 10,000 daily unique visitors, assuming an average session duration of 3 minutes and a conservative 50% thread allocation.

Frequently Asked Questions

Does Earnify slow down my static site?

No. Earnify runs in a dedicated Web Worker, keeping the main thread free for UI interactions. Page load times and responsiveness remain unaffected. In our benchmarks, even on low-end devices, the impact on Core Web Vitals was negligible when thread usage was capped at 50%.

Can I use Earnify with any static host?

Yes. Since Earnify is just a JavaScript file you include, it works on Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any CDN. There’s no backend to configure.

Is browser mining profitable for small sites?

Profitability scales with traffic and session length. A niche blog with 1,000 daily visitors might earn $3–$10 per month. It’s best viewed as a supplementary revenue stream, not a primary income source. Pairing Earnify with affiliate links or sponsored content often yields the best results.
