What this demo proves

1. Auto-detect: the badge above mirrors coinPass() — ltc1/L/M → c=LTC, R → c=RVN, else c=DOGE. The same password is sent as the Stratum password field when you press Start.

2. Live callbacks: hashrate here comes from the onHashrate({ hashrateKHs }) callback — newminer.js has no global hashrate object (unlike v1 miner.js → minotaurxHashrate). See docs for the migration note.

3. Fee honesty: exactly 1 fee thread, and a 180 s watchdog stops everything if fee work stalls. Confirm shares on zpool.ca/wallet/<address>.
