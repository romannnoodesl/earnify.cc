Privacy Policy

Earnify collects no personal data — on this website, in the demo, or in the miner library you embed. This policy explains what we process, why, and the regulatory analysis behind it.

1. What We Collect On This Website

Nothing requiring consent. This site uses no analytics cookies, no advertising pixels, and no third-party trackers. Hosting providers (GitHub Pages / Cloudflare Pages) may log standard connection metadata (IP address, user agent, request logs) for security and rate limiting, the same as any web server. That data is not accessed, monetized, or augmented with cross-site information. The contact form delivers messages to the team via Telegram; only the information you type is transmitted.

2. The Mining Library

Earnify's miner (miner.js / miner.min.js) is designed around one rule: process no personal data. Concretely:

  • No cookies — nothing is stored on or read from the visitor's device.
  • No localStorage, no IndexedDB, no Cache API — the miner never touches storage.
  • No fingerprinting — no canvas, no user agent collection, no device identification.
  • No user identifiers — the Stratum protocol carries only a worker label you configure (e.g., your wallet address).
  • Ephemeral execution — Web Workers exist only for the page session; nothing persists.

3. GDPR / CCPA Analysis

Under GDPR Article 4(1), personal data is any information relating to an identified or identifiable natural person; the mining integration collects, stores, and transmits none. Under CCPA/CPRA, a business that does not collect, share, or sell personal information has no disclosure or opt-out obligations for the integration. Under the ePrivacy Directive, the integration stores nothing on, and accesses nothing from, terminal equipment — so no cookie banners are required for the miner itself. We are not a law firm, and publishers should always review their own configurations with their counsel.

4. Opting Out

Publishers who embed Earnify provide their own opt-out UI; the library exports a stop() method to terminate mining instantly. End users can also disable JavaScript or Web Workers on any page to prevent mining entirely.
